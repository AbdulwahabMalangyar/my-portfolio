# Abdulwahab Saraji — Responsive Portfolio

A responsive React + Vite portfolio with English, Pashto, and Dari language switching, RTL layout for Pashto/Dari, Facebook-inspired blue styling, dark/light mode, mobile navigation, project/education sections, and contact links.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code or a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown by Vite.

## Before publishing

- Confirm the contact email in `src/pages/Contact.jsx`.
- Confirm the WhatsApp number in `src/pages/Contact.jsx` and `src/component/Footer.jsx`.
- Replace the LinkedIn placeholder in `src/component/Footer.jsx` with your real profile.
- Add real repository/demo URLs for project cards in `src/pages/Projects.jsx`.
